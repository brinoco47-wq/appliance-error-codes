How to Read an Appliance Error Code

Guide · 2026-10-20

An error code is your appliance's way of pointing at a problem area — it is a clue, not a diagnosis. Most codes combine a letter (the system: water, drain, door, motor) with a number (the specific fault). The same code on two brands can mean different things, and sometimes the same brand reuses a code across model families with different meanings.

Before you search: note three things

  1. The exact code, exactly as shown. Case matters on some machines (LG's lowercase uE and uppercase UE are different stages of the same problem). Photograph the display if you can.
  2. Brand and appliance type. A washer code and a dishwasher code that look alike are unrelated.
  3. Your model number. It turns a generic code page into the right answer for your machine. See how to find your model number.

What a code can and cannot tell you

A code can tell you which system reported a problem — water inlet, drain, door lock, motor, vent. It cannot tell you which part has failed. A drain code, for example, can be a kinked hose, a blocked filter, or a dead pump. Work through the cheap, visible causes first before assuming a part has failed.

When the same code appears on another brand

Never carry a meaning across brands. For example, LE on an LG washer means a locked or overloaded motor. Other brands use the same letters for other faults. Always search by brand and appliance together — that is why this site's search asks for both.

What to do with a code you cannot find here

Check your model's manual first (search the model number plus the code). If the code is not documented anywhere, treat it as a prompt to call the manufacturer's support line with the model number ready — not as permission to open the machine.
