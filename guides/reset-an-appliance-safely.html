How to Reset an Appliance Safely

Guide · 2026-10-16

A reset (usually a power cycle: unplug, wait, plug back in) clears the machine's electronics back to a known state. It fixes one-off glitches — a sensor hiccup after a power cut, a control confused by a voltage dip. It does not fix blockages, leaks, or broken parts.

The safe power-cycle routine

  1. Switch the appliance off at its own controls.
  2. Unplug it (or switch the breaker off if the plug is unreachable).
  3. Wait at least one full minute so the electronics discharge.
  4. Plug back in, switch on, and run a short cycle.
  5. Watch whether the code returns immediately, later in the cycle, or not at all — that timing is useful information.

When resetting is the wrong move

  • An active leak. Resetting a dishwasher showing a leak code just lets it leak again.
  • A burning smell or scorching. Do not power it back up.
  • A gas smell. Do not touch switches at all — leave and call the gas utility.
  • A dryer airflow warning (d90/d95). The vent is still blocked; running it again is a fire risk.

If the code returns straight away

The fault is still present. Work through the code's own checks on this site instead of resetting repeatedly — repeated resets hide nothing and fix nothing.
